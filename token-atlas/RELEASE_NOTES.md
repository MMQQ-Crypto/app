# Token Atlas 1.3.0

- 新增应用内更新：启动后检查新版，支持手动检查、下载进度、SHA-256 校验及免安装版覆盖更新后重启。
- 更新仅使用 Token Atlas 专用发布标签与清单，不读取或替换仓库内其他应用的更新文件。
- 保留 DeepSeek Harness 压缩日志自动读取、国内模型分类、真实网页 usage 采集与 JSON / JSONL / HAR 导入。
- 更新保留原有设置与采集记录，旧程序备份为同目录的 `.previous` 文件。

网页端只有在实际返回 usage 时才能准确记录；未返回的用量不会估算。更新校验用于验证下载完整性，使用的发布源为本项目 GitHub 仓库。
